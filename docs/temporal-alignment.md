# 도착·체류시간과 혼잡 예측 정렬

2026-09-17 사용자 보완 요청에 따른 2단계 확장. `temporal.ts`의 순수 함수가 수동 시각과 제공 예측을 연결한다. TMAP·현재 위치 수집·추가 유료 API·AI 호출은 이번 변경에 포함하지 않는다.

## 공식 자료와 자체 계산

서울시 `FCST_TIME`, `FCST_CONGEST_LVL`, `FCST_PPLTN_MIN/MAX`를 기존 서버 정규화·캐시에서 받는다. 원본 스냅샷을 수정하거나 보간 표본을 원자료 캐시에 삽입하지 않는다. 사용자별 후보만 계산하며 저장하지 않는다.

- 시각 일치: 공식 단계·인구 범위를 그대로 사용한다.
- 시각 사이: 같은 장소·같은 스냅샷의 바로 앞뒤 표본을 사용한다. 간격 최대 60분은 숨맵의 제품 정책이다.
- 인구 범위 양끝만 `w=(도착-앞 시각)/(뒤 시각-앞 시각)`, `값=(1-w)×앞 값+w×뒤 값`으로 계산한다. 내부 소수·실제 weight를 보존하고 화면 인구는 약 100명 단위로 표시한다.
- 17:23, 14,000~16,000 → 18,000~21,000의 예: w=23/60, 내부 15,533.333…~17,916.666…명, 화면 약 15,500~17,900명. w를 먼저 0.383으로 자르지 않는다.
- 인구 범위 한쪽 누락·비정상이면 인구 보간만 생략한다. 유효한 혼잡 표본은 사용할 수 있다.
- 보간 범위는 공식 예측·통계적 신뢰구간·오차 범위가 아니다. 원본 min/max의 통계적 의미를 임의로 가정하지 않는다.
- 혼잡 단계는 순서만 비교한다. 단계 평균·소수 단계·인구에서 역산한 임계값을 만들지 않는다. 서로 다른 크기의 공원을 인구 수로 정렬하지 않는다.
- 표본이 한쪽만 있거나 예측 범위 밖이면 외삽하지 않는다. 현재 관측을 예측 대신 섞지 않는다.

보간 계산은 검증했으나 분 단위 실제 인구에 대한 정확도 향상은 검증하지 않았다. 동일 단계 표본 사이에서도 급증할 수 있다. ‘안정’ 대신 ‘평가에 사용한 예측 표본은 같은 혼잡 단계’라고 표시한다.

## 체류와 자료 범위

체류시간이 있으면 [도착, 도착+체류시간] 양끝을 포함해 검사한다. 시작·끝을 둘러싼 표본과 내부 모든 표본을 사용한다. 17:23~18:23이면 17·18·19시가 근거다. 종료가 정확히 18시이면 19시 표본은 포함하지 않는다.

각 예측 시각에서 구간을 나누어 모두 앞뒤 표본이 있고 간격이 60분 이하인지 확인한다. 시작·끝이 보통이어도 중간 붐빔 표본을 놓치지 않는다. 일부만 평가 가능하면 `partial`, 근거가 없으면 `unavailable`이다. 불완전 후보는 추천에서 제외하며 원래 계획이면 누락 구간이 보이는 참고 카드로 유지한다.

체류시간 `null`은 도착 순간만 평가한다. `complete`는 정책에 맞는 표본으로 구간을 둘러쌌다는 뜻이며 연속 관측이나 실제 혼잡 보장이 아니다.

## 선호 판정과 정렬

| 판정 | 기준 |
|---|---|
| supported | 자료 범위가 완전하고 모든 평가 표본이 선호 이내 |
| uncertain | 자료 범위는 완전하지만 경계 전후 표본이 선호를 넘나듦. 방문 구간 내부에 초과 표본은 없음 |
| exceeds | 방문 구간 내부/정확한 도착 시각에 초과 예측이 있거나, 평가 표본이 모두 선호 초과 |
| unknown | 필요한 구간 자료 부족 |

supported 후보가 있으면 그 안에서 선택한다. 없으면 uncertain을 `preference-uncertain`으로 표시한다. 둘 다 없으면 완전한 후보 중 덜 붐비는 안을 `preference-unmet`으로 표시한다. 어떤 경우도 사용자 필수 조건이나 지연 자료 허용 여부를 자동 변경하지 않는다.

정렬의 혼잡 기준은 ‘평가 표본 중 가장 높은 단계’이며 새로운 공식 단계가 아니다. 변경 최소는 변경 항목 수 → 장소 유지 → 시간 차이 → 위 표본 단계다. 혼잡 우선은 표본 단계를 먼저 비교한다. 기존 항목이 모두 같을 때 동일 단계 표본을 우선하고, 도착 시각·장소 ID로 동률을 고정한다. 모두 선호 이내인 여유→보통 구간을 단순히 변화가 있다는 이유로 불합격시키지 않는다.

시간 후보는 원래/고정 시각, 허용 범위 양끝, 공식 예측 시각, 체류 종료가 공식 표본과 만나는 도착 시각의 합집합이다. 이후 필수 조건으로 거른다. 1분 간격의 가상 시계열을 생성하지 않으며 연속 시간 전체에서 최적해를 보장하지 않는다. 17:23 고정을 17시나 18시로 바꾸지 않는다.

## 근거와 향후 연결

`Candidate.arrival`: exact/between, 공식 근거 표본, 인구의 official/linear-estimate, 시간 비율. `Candidate.visit`: 범위·누락 구간·근거 표본·변화 방향·선호 판정. 모든 근거는 snapshot ID와 실제 예측 시각으로 추적한다. 최상위 `Candidate.congestion`은 제거해 이후 AI가 보수적 비교 단계를 특정 시각의 공식 예측으로 오독하지 않게 한다.

LLM은 향후 결과를 설명하며 계산·정렬에는 관여하지 않는다. TMAP 미연결이므로 현재 시각 입력은 수동이다. 교통 연결 시에는 실제 공원 입구, 권한 거절 대안, 이동시간 불확실성, 호출 상한을 별도로 검증해야 한다.
