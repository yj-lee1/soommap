## AI 활용 방식 및 결과 (444/500자)
“지금 한강에서 한 시간 걷고 싶어. 사람 많은 곳은 피하고 싶어.”라는 말을 AI가 장소·시간·체류·혼잡 선호로 구조화합니다. 서울시 혼잡 예측과 TMAP 이동시간을 결합해 도착해서 머무는 동안의 대안을 비교합니다. 장소·시간을 고정하면 지킬 조건을 보존한 채 변경이 적은 안부터 다시 제안합니다. OpenAI API(gpt-5.6-terra)는 조건 해석과 계산된 근거 설명을 맡고, 조건 검증·추천 정렬·시각 정렬은 코드로 처리해 버튼 조정에 AI를 재호출하지 않습니다. 공식 혼잡 단계·숨맵 인구 추정·예측 공백을 구분합니다. 한강공원 5곳에서 추천→고정·재비교→계획 저장→네이버·카카오 길찾기를 구현하고, 실제 API 통합 검증과 자동 검사 117개를 통과했습니다. TMAP 한도 소진 시 수동 시간대 비교를 제공합니다. ChatGPT로 기획하고 Codex로 구현·테스트·배포했습니다.
