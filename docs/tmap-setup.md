# TMAP 연결 설정

개발·검수 총 5,000원 승인은 이미 반영됐다. 아래는 계정 상품과 키를 연결하는 사용자 작업이다. 키를 채팅에 보내지 않는다.

1. [SK Open API](https://openapi.sk.com)에 본인 T아이디로 로그인한다.
2. 대시보드의 **앱 → 앱 만들기**에서 숨맵 전용 앱을 만든다. 이미 만든 전용 앱이 있다면 재사용한다.
3. **TMAP 대중교통 → 대중교통 요약정보** 상품을 선택한다. 승인한 종량제로 진행하려면 신청 화면의 가격·과금 조건을 확인하고 직접 신청한다. 무료만 연결하려면 Free 상품을 선택한다. 다른 자동차/도보 상품이나 월정액을 추가할 필요는 없다.
4. 앱의 **appKey**를 `/Users/yeongji/Dev/Wanted/.env.local`의 `TMAP_API_KEY=` 뒤에 입력한다.
5. 종량제 신청을 완료했다면 `TMAP_BILLING_MODE=paid`, Free라면 `TMAP_BILLING_MODE=free`로 저장한다.
6. 채팅에는 키 없이 **‘TMAP 설정 완료’**라고 알려준다.

이후 Codex가 예산 장부를 보존하면서 실제 요약 경로를 최소 1건 검증하고, Preview 환경변수만 추가한 후 재배포한다. Production에는 아직 키를 추가하지 않는다.

공식 요약요금은 0.55원/건으로 확인했다. 서버는 실패·시간 초과를 포함해 1원/건씩 보수적으로 예약하며 누적 예약 5,000원에서 중지한다. 무료 모드는 하루 10건, 종량제 모드는 하루 최대 1,000건이다. 이 서버 밖에서 같은 키를 사용한 비용은 이 장부에 포함되지 않으므로 전용 앱 키를 사용한다.

화면이 다르면 상품명과 현재 화면의 메뉴만 알려주면 된다. 앱 키나 결제정보는 보내지 않는다.
