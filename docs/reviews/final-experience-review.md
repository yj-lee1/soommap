# A안 디자인 통합·최종 경험 검수

2026-09-19. 6~8단계 연속 진행과 원티드 임시저장 지시에 따른 기록. 사용자 실제 기기 검수나 출시 승인을 대신하지 않는다.

## 반영 내용

밝은 종이색, 먹색 본문, 절제한 녹색 동작, 명조 제목과 고딕 본문을 사용했다. 시작은 자연어와 출발지, 결과는 원래 계획·고정 조건·변경 이유, 확정은 같은 카드의 출발·도착·길찾기 순서다. 장식용 대시보드 지표나 임의 혼잡 그래프를 추가하지 않았다. 아이콘·공유 이미지·자료/위치/저장 안내도 통일했다.

디자인과 구분되는 UX 변경은 첫 방문을 목적지·정확한 도착시각 미정/자동 도착으로 시작하도록 한 것, 오류 후 수동 시간대 전환 단추, 고정 단추의 눌림 상태와 해제, 결과 제목 포커스다. 추천 엔진, 시간 정렬 정책, 서버 API 계약, 비용 예약/정산은 변경하지 않았다.

## 검증 근거

- 기존 자동 검사 117/117 통과. TypeScript·ESLint·production build 통과.
- 새 UI의 모의 통합: 목적지/도착시각 미정 → 서울역 설정 → TMAP 도착 계산 → 자연어 60분/보통 선호 → 추천 → 반포 고정 → 도착시각 고정 → 선택 → 확정 → 출발지/접근 지점과 지도 단추 표시.
- 위 흐름의 모의 공급자 기록: 서울시 5건, TMAP 5건, AI 조건 해석/설명 각 1건. 슬라이더·고정·선택·확정으로 AI/TMAP 추가 호출 없음. 이 모의 기록은 실제 비용·실연동 증거가 아니다.
- 시간축 화살표 조작: 탐색 09:54~10:54로 변경해도 추천/고정 09:53 유지. 공식 시점과 자체 인구 보간 구별, 표본 사이에 혼잡 단계를 그려 넣지 않음.
- 새로고침: 문장·서울역·반포 09:53 확정 계획 복원. 이전 예측/ETA는 최신 값으로 복원하지 않고 안내 표시. 별도 AI/TMAP 자동 호출 없음.
- TMAP 한도 실패를 모의 주입: 입력/출발지 유지, 직접 시간대 전환, TMAP/AI 없이 수동 추천 성공.
- AI 실패를 모의 주입: 원문 유지, 오류와 수동 비교 제공. 브라우저 오류 로그 없음.
- 320px/390px 가로 넘침 없음. 키보드 시간축, 포커스, 누름 상태, 최소 44px 조작 영역 검토. 동작 줄이기에서 animation:none 확인. OS reduced-motion도 CSS 적용.
- 본문/보조/동작/경고 글자 대비 5.76~13.54:1, 컨트롤 경계 3.43:1(밝은 표면 기준). 색 외에 문구·원형 표본·빗금 공백으로 상태 구별.
- 빌드 클라이언트 파일에서 실제 환경변수의 비밀값 5종 검색 결과 0건. 값은 기록하지 않음.

## 재사용한 실연동과 남은 항목

| 흐름 | 상태/근거 |
|---|---|
| 자연어 → 실제 AI 구조화 | 실제 연동 검증 완료(3단계·9/18); 새 UI 모의 검증 추가 |
| 출발역 → 실제 TMAP ETA → 서울시 예측 | 실제 연동 검증 완료(4.5단계·9/18); 새 UI 모의 검증 추가 |
| 조건 고정·재추천·선택 | 실제 연동 검증 완료(4~5단계·9/18); 새 UI 모의 검증 추가 |
| 예측 범위 밖·공백·오래된 자료·선호 불충족 | 엔진 자동 검사 및 기존 단계 모의/실제 공백 증거 재사용; 새 CSS 표시 |
| 저장·복원 | 5단계 실제 검증 + 새 UI 브라우저 모의 검증 |
| 네이버 앱 연결 | 사용자 연결 성공 확인 재사용 |
| GPS 거절·카카오 앱·미설치 앱 fallback | 기존 모의/링크 검사, 실제 모바일 기기 미검증 |
| 설명 없이 첫 사용 이해 | 내부 휴리스틱 검토만 완료; 실제 사용자 관찰 미실시 |

처음 사용자 관점에서 입력 순서/다음 행동/변경 이유/자료 한계가 보이는지 내부 점검했다. 실제 사용자 3명 관찰이나 사용성 수치를 만들지 않는다. 계획의 실제 AI 문장 10~15개 반복 호출은 이번 디자인 변경만을 위해 수행하지 않았다. 기존 실연동과 117개 경계/조건 검사를 재사용했다.

## 운영 제한

사용자의 최신 결정에 따라 TMAP Free 하루 10건을 유지한다. 공원 5곳 새 계산은 최대 5건이며 한도 이후 자동 ETA는 사용할 수 없다. 수동 시간대 비교와 최종 지도 연결은 유지된다. 유료 전환 미실행. OpenAI $20 atomic 원장과 기존 제한은 보존한다.

서비스 범위는 한강공원 5곳의 산책이다. 소음 측정, 서울 전체 추천, 자체 혼잡 예측, 미래 출발 경로 예측을 구현했다고 쓰지 않는다. 공개 URL은 기존 고정 Preview alias로 운영하며 Production 별도 환경은 구성하지 않는다.
