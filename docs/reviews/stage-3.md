## 완료 범위

자연어 → Structured Outputs → 서버 검증 → 기존 조건 모델 → 실제 서울 예측/도착·체류 비교 → 근거 설명이 공개 URL에서 작동한다. 모델은 승인된 `gpt-5.6-terra`다.

명시한 장소·시각 고정과 늦추기 범위를 보존한다. 목적지·체류시간 미정은 임의 값으로 채우지 않는다. ‘저녁’ 등 제안 범위는 가정으로 표시하고, 오전/오후처럼 중요한 모호성은 확인 안내를 반환한다. 지원하지 않는 희망은 평가하지 못한 조건으로 표시한다. 자연어 해석 이후 수동 폼으로 조건을 수정할 수 있고 재비교는 AI를 호출하지 않는다.

설명 AI는 계산된 사실 문장 ID 1~3개를 고른다. 실제 장소·시각·혼잡 수치는 검증된 코드의 문장을 출력하므로 임의 생성한 설명이 화면에 들어오지 않는다. 선택 ID가 유효하지 않거나 설명 호출이 실패하면 추천을 유지하고 계산 근거로 대체한다. 해석 실패 시 입력을 보존한다.

Upstash Free를 공유 예산, 사용자·IP 빈도 제한, 흐름/호출 중복 방지, 암호화한 5분 TTL 결과 캐시에 함께 사용한다. 사전 예약·정산·한도 검사는 atomic Lua로 수행한다. Supabase와의 비교·보관 내용·이전 설정은 [설계 문서](../ai-runtime.md)를 따른다. Preview에만 Redis 비밀 환경변수 2개를 추가했다. 유료 기능/플랜/결제수단을 변경하지 않았다.

1. **장소 고정/늦추기**: “오늘 오후 7시에 여의도한강공원에서 한 시간 산책할래. 장소는 바꾸지 말고, 최대 한 시간 늦어도 괜찮아. 보통보다 붐비면 싫어.” → 여의도만, 도착 19:00~20:00, 60분, 보통까지. 실제 자료에서 원래 19시 계획 유지, 20시는 다른 선택. 해석·설명 2회 성공.
2. **목적지 미정/제외**: “오늘 저녁 7시부터 9시 사이에 한 시간 산책하고 싶어. 목적지는 아직 못 정했어. 망원은 빼고 보통보다 붐비는 곳은 싫어.” → 원래 장소·시각 null, 19~21시, 60분, 망원 제외. 실제 예측으로 추천 생성, 해석·설명 2회 성공.
3. **모호한 시각**: “내일 5시에 여의도한강공원에서 한 시간 산책하고 싶어.” → 오전/오후 확인 안내. 해석 1회에서 종료, 추천·설명 생성 없음.

첫 화면 검증의 계산 시점은 17:22, 원자료 16:50/수신 17:22로 **32분 전 자료**였다. 검수자가 지연 예측 참고를 선택한 상태에서 계산했고, 카드·AI 근거 모두 지연 표시를 유지했다. 최신 관측으로 표현하지 않았다. 추천 장소/시각은 이후 실제 자료에 따라 달라질 수 있다.
