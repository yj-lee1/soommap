# 1단계 검수 보고 — 한강 5곳 실제 데이터 기반

2026-09-17 · 상태: 로컬 자체 확인 완료, 공개 Preview 검증 진행 중.

작업 브랜치: `feat/hangang-data-foundation`. 검수 배포 후 실제 URL·코드 버전과 브라우저 결과를 아래에 기록한다. `main`·Production은 변경하지 않는다.

## 완료한 범위

- 서울시 공식 코드·집계 영역과 대조한 한강공원 5곳. 장소 구조는 활동·그룹·영역·표시점을 분리해 확장 가능하게 구성.
- 현재 관측과 제공된 예측을 분리하고 원자료 시각·수신 시각·대체 자료·결측·최신성 정규화.
- 서버 전용 조회, 5분 공용 캐시, 같은 worker의 동시 요청 병합, 8초 제한, 실패 재시도 대기, 마지막 정상 자료 유지.
- 공원별 실제 자료·예측 표·출처·재확인 버튼·로딩·오류 화면. 장식 디자인은 후순위 유지.
- 표준 Next.js Data Cache, 환경변수와 통신 어댑터 분리. 상시 작업이나 유료 Vercel 옵션 추가 없음.

## 수행한 검증

| 실제 장소 등록 검사 | 5곳 모두 정상 응답, 대체 자료 아님, 공통 예측 12개 확인 |
| 동시 요청과 화면/API 캐시 | 모의 서버에서 API 5개 병렬 + 추가 API + 페이지 요청의 원본 조회가 장소별 1회, 합계 5회 |

| 서버 재시작 | 같은 캐시에서 원본 오류 상태로 재시작해도 기존 5개 스냅샷 유지 |
| 부분 실패 화면 | 빈 캐시에서 반포만 모의 실패: 반포는 자료 없음, 다른 4곳 계속 표시, 전체 비교 보류 |

반복 장애·통신 검사는 실제 API와 분리한 로컬 fixture이며 공개 서비스에 예시 자료를 제공하지 않는다.

## 비용·제한

- 이번 단계 OpenAI **0회 / $0**. 누적 보수적 추정 **$0.000616**, 예산 기록 예약 **$0.05** 유지. 승인 총액은 **$20**.
- Vercel Hobby 유지. 검증된 프로젝트·Preview 키 재사용, Production 환경은 별도 유지.
- 자료가 30분 넘게 지연되거나 10분 넘게 새 수신이 없으면 최신 추천 가용 상태에서 제외한다. 결측을 여유로 바꾸지 않는다.
- 공원 단위 추정값이다. 세부 산책로·소음·머무는 전체 시간의 상태를 보장하지 않는다.
- 캐시는 영구 DB나 분산 락이 아니다. 여러 worker의 동시 첫 요청은 제한적인 중복이 가능하고, 캐시 퇴거와 원본 장애가 겹치면 자료 없음으로 표시한다.
- 실제 추천·조건 입력·AI 해석은 아직 다음 단계다. 상세 근거는 [데이터 문서](../data-foundation.md)를 따른다.

## 사용자 검수 방법

1. 검수 URL에서 한강 5곳과 자료 기준 시각·마지막 수신 시각을 확인한다.
2. 공원의 `앞으로의 예측 …개 보기`를 펼쳐 한국 시간·혼잡 단계·추정 인원을 확인한다. 수는 현재 제공된 자료에 따라 달라질 수 있다.
3. `자료 다시 확인`을 누르고 화면이 정상 유지되는지 확인한다. 캐시·서울시 갱신 주기 안에서는 같은 자료가 보이는 것이 정상이다.

사용자가 요청한 단계별 검수 방식에 따라 승인을 기다린다. 승인 후 **2단계: 수동 조건 입력과 추천 엔진**을 진행한다.
