## 완료 범위

처음 비교 조건을 보존한 채 후보의 장소·도착시각을 추가 고정하고 해제한다. 해제하면 처음 허용한 범위로 돌아간다. 처음부터 고정한 조건은 수동 폼에서 명시적으로 바꿔야 한다. 공원 제외·복원, 모두 제외하거나 고정 장소를 제외한 충돌도 안내하며 자동으로 조건을 풀지 않는다.

목적지를 정한 시작과 아직 못 정한 시작을 구분한다. 목적지 미정은 허용 장소·방문 시간 범위로 비교한다. 원래 장소·도착시각은 추가 조정이나 후보 선택만으로 바뀌지 않는다. ‘망원은 빼줘’, ‘반포로 고정’, ‘19시 고정’, ‘시간 고정 해제’, ‘그럼 시간만 늦추자’ 등 **제한된 짧은 명령**은 같은 코드 규칙으로 처리한다. 부정·복합·모호한 명령은 추측 적용하지 않고 입력 안내를 반환한다. 임의의 자유문장 후속 대화를 모두 처리하는 기능은 아니다.

선택 → 해당 장소·시각 자료 검사 → 근거 확인 → 확정 → 문구 복사·공원 대표 위치 링크 → 다시 조정까지 연결했다. 후보 카드에는 지도 버튼이 없다. 확정 전 선호를 넘거나 불확실한 예측은 별도 확인을 요구한다. 다시 검사했을 때 근거가 같으면 확정을 유지하고, 달라지면 선택은 유지하되 재확정하도록 한다. 선택한 계획 대신 다른 추천으로 자동 교체하지 않는다.

계획 검사에는 기존 서울시 캐시와 추천 엔진을 재사용한다. 조건·선택 요청 버전을 따로 관리해 뒤늦은 응답을 무시한다. 조건을 수정하면 이전 선택·확정이 사라진다. 검사 후 5분, 도착시각 경과, 자료 최신성 한계 초과 시 재확인 전 확정·복사를 막는다. 서버 상시 작업 없이 사용자가 재확인할 때 검사한다.

## 비용·남은 제한

- 이번 단계 실제 OpenAI 추가 생성 **0회 / $0**. 버튼·짧은 정정·선택 검사는 AI를 호출하지 않는다.
- 기존 원장 조회: 누적 usage 추정 **$0.019032**, 보수적 예산 반영 **$0.068416 / $20**. 기존 연결이나 Redis 동시성 검사는 반복하지 않았다.
- 선택은 현재 탭 안에서 유지하며 새로고침하면 초기화된다. 서버에 개인 계획을 저장하지 않는다.
- 이번 지도 링크는 [카카오 공식 위치 링크](https://apis.map.kakao.com/web/guide/) 형식의 공원 대표 위치다. TMAP 이동시간, 접근 지점, 출발지를 재사용하는 네이버·카카오 대중교통 길찾기는 승인 후 **4.5단계**에서 연결한다.
- 사용자 경험 구조·기본 모바일 조작을 우선했고 시각 디자인은 기존 계획대로 후순위다.

## 확인 요청

1. 미래 도착시각과 ‘최대 2시간 늦어도 괜찮아요’, 다른 공원 변경 허용을 선택해 비교한다. 후보 시각/장소 고정 후 해제할 때 처음 범위로 돌아오는지 확인한다.
2. ‘이번에는 이곳 제외’ 또는 ‘망원은 빼줘’를 적용하고 복원한다. 고정한 장소를 제외하면 충돌 안내와 복원 버튼이 보이는지 확인한다.
3. 후보 선택→계획 확정→계획 문구 복사→자료 다시 확인을 진행한다. 조건을 바꾸면 이전 확정 상태가 사라지는지 확인한다.

자료가 30~60분 이전이면 ‘지연 예측 참고 비교’를 허용해야 비교할 수 있다. 요청받은 단계별 검수 방식에 따라 승인 후 4.5단계를 진행한다.
