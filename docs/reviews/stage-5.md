## 검수 방법

1. **고정 검수 URL**에서 원하는 조건과 출발지를 입력하고, 필요하면 계획을 확정한다. 사이트를 나갔다가 **같은 주소·브라우저**로 돌아와 내용이 복원되는지 확인한다.
2. 저장된 확정 계획에서 네이버/카카오 길찾기로 바로 이어지는지 확인한다. 지난 예측·이동시간을 현재 정보로 표시하지 않는지 확인한다.
3. 공원 위치와 예측 영역의 지도·공원 버튼을 선택하고, 후보의 체류 그래프를 확인한다. 장소 탐색이 입력 조건을 바꾸지 않아야 한다.
4. 저장 내용을 지우고 새로 시작할 수 있는지 확인한다. 삭제하면 이 브라우저의 입력·출발지·선택 기록이 지워진다.

저장 도입 전 이전 배포에서 입력했던 내용은 소급 복구되지 않는다. 무작위 배포 URL과 고정 URL은 서로 다른 브라우저 저장소다. 앞으로 검수에는 고정 URL을 사용하고 이후 Preview도 같은 alias로 연결한다.
