# 0단계 중간 보고 — 저장소·개발 환경

2026-09-17 · 상태: 기반 작업 확인 완료, 외부 설정 대기 · 0단계 전체 완료 아님

## 완료한 범위

- 지정 원격의 `main` 이력에서 `codex/soommap-build` 작업 브랜치 생성. 기존 문서 보존.
- Next.js 16.3.5, React 19.3.0, TypeScript 프로젝트와 Node.js 24 실행 구성.
- 개발 검수용 기본 화면과 웹 서버 연결 확인 버튼.
- `Place`, `Snapshot`, `Conditions`, `Candidate`, `Recommendation` 공통 타입. 실제 추천 로직은 아직 미구현.
- `/api/health`와 인증이 필요한 `/api/setup/status`. 후자는 키 값을 출력하지 않고 설정 여부만 반환.
- `.env.example`, Git에서 제외되는 `.env.local`, 환경 설정 안내와 연결 확인 스크립트.

## 수행한 확인

| 항목 | 결과 |
|---|---|
| `npm run check` | 타입 검사·ESLint 통과 |
| `npm run build` | 배포 빌드 통과 |
| `npm ls --depth=0` | 설치된 직접 의존성 확인, 오류 없음 |
| 웹 화면 | 로컬 기본 화면의 데스크톱 및 390px 폭 확인 |
| `npm run check:setup` | 로컬 서버와 인증된 설정 확인 경로 응답 성공 |
| 인증 없는 설정 조회 | 404 응답으로 차단 |
| 비밀값 제외 | `.env.local`과 빌드·의존성 파일이 Git 제외 대상임을 확인 |
| 서울 API·AI API | 키 미설정, 실제 인증·응답은 아직 확인하지 못함 |
| 공개 배포 | 호스팅 선택·인증 대기 |

ESLint는 현재 Next.js 검사 플러그인과 호환되는 9.39.5로 고정했다. 지원 종료 안내가 있으며 상세 배경은 환경 설정 문서에 기록했다.

## 필요한 사용자 입력

1. 호스팅 선택: Vercel을 제안했으며 사용자 응답 대기.
2. AI 공급자와 테스트·운영 비용 한도.
3. 서울 열린데이터광장 키 발급 여부 및 로컬 설정.
4. 참가 신청 완료 여부는 다음 확인에 포함.

키는 `/Users/yeongji/Dev/Wanted/.env.local`에 입력한다. 채팅에는 키 대신 설정 여부만 알려주면 된다. 서울시 키 발급 절차는 [환경 설정 안내](../environment-setup.md)를 참조한다.
