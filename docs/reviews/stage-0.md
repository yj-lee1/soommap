## 배포 중 발견한 사항과 처리

1. GitHub 자동 연결은 Vercel의 저장소 접근 권한 문제로 실패했다. GitHub push와 Vercel CLI Preview 배포를 분리해 정상 완료했다. 지금 검수에는 추가 권한 설정이 필요하지 않다.
2. `--target=preview`로 요청한 첫 배포가 Vercel에 의해 자동 Production으로 분류됐다. 다음 배포가 실제 Preview인 것을 확인하고 초기 자동 Production 배포 1건을 제거했다. 최종 목록은 Preview 1건만 남았으며 기본 운영 주소 `soommap.vercel.app`과 제거된 주소는 404, 검수 주소는 200이다. 최종 서비스 배포는 아직 하지 않았다. [Vercel의 첫 배포 자동 승격 설명](https://vercel.com/blog/default-production-domain)
3. ESLint는 현재 Next.js 플러그인 호환성을 위해 9.39.5로 고정했다. 지원 종료 안내가 있으며 환경 문서에 남겼다.
