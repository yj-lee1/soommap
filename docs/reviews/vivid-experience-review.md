# A안 색·모션·추천 구성 개선

2026-09-19 사용자 후속 승인. `feat/vivid-walk-experience`에서 작업. 기존 추천 엔진, API 계약, 서버 예산/빈도/TTL, 모델, TMAP Free 설정은 변경하지 않는다.

## 반영

- 공원 녹색·강물 파랑·햇빛 노랑으로 대표 추천과 시작 화면의 큰 색면 구성. 명조는 주요 제목에 집중하고 도착시각·조건은 고딕으로 정리.
- 원래 요청/출발지/공식 위치 지도를 데스크톱 옆면에 고정. 모바일은 같은 정보를 간결하게 표시하고 고정 조건을 추천 위에 유지.
- 추천 상단에서 유지한 장소/시각, 변경한 항목, 체류 평가 이유를 표시. 미정인 계획은 가상의 원래 계획을 만들지 않는다. 제외 후보에 조건 충족을 주장하지 않는다.
- 공식 집계 영역의 정적 지도: 공원 대표 위치와 선택한 영역만 강조. 지도·범위 선택으로 외부 API 호출 없음. 강 경계·경로·혼잡 분포로 표현하지 않음. 기존 공개 GeoJSON과 동일한 좌표를 번들에서 재사용.
- ① 고정 조건 유지, 바뀐 장소/시각만 전환 ② 파란 체류 띠로 공식 예측 시점 탐색 ③ 같은 카드에서 선택/확정/길찾기로 크기 전환, 확정 표시. 첫 화면의 강·해·나무는 짧은 일회성 브랜드 일러스트.
- 공식/보간/예측 공백, 선호 불충족과 지연 자료 구별. 조회 한도·AI 실패는 입력을 보존하고 수동 비교로 연결.
- 확정 버튼이 사라질 때 확정 제목으로 키보드 포커스 이동. 추천 결과 포커스는 고정 영역 아래에 표시.
- 신규 라이브러리/유료 기능 없음. 서버 호출 없는 CSS/SVG/Web Animations 사용. OS 및 화면 동작 줄이기에서 애니메이션 해제.

## 검수

- 기존 자동 검사 117개, TypeScript/ESLint, production build 통과.
- 모의 공급자에서 자연어→서울역→5곳 ETA→반포 추천→장소/시각 고정→시간축 ArrowRight→선택→확정→네이버/카카오 버튼 확인.
- 11:23 고정 이후 시간축 탐색값만 11:24로 변경. 선택 시각은 11:23 유지. 이 흐름의 모의 TMAP 5회·AI 2회, 고정/탐색/선택/확정 추가 호출 0회.
- 새로고침 후 입력·출발지·고정·확정 계획 복원, 이전 예측/ETA는 복원하지 않음. 기존 저장 형식 보존.
- 모의 AI 실패 및 다른 출발지의 TMAP 한도 실패 확인. 입력·출발지를 유지하고 수동 시간대 비교로 진행. `여유` 선호에 `보통`인 결과는 선호 미충족을 명시.
- 320/390px 가로 넘침 없음. 키보드 시간축/포커스, 44px 버튼, 문자+기호 상태 확인. 화면 동작 줄이기에서 animation:none, transition:0s 확인.
- 주요 글자 대비 5.14~8.43:1, 입력 테두리 3.76:1. 클라이언트 정적 빌드에 실제 비밀값 5종 검색 결과 0건(값 미기록).
- 기존 실연동 검증은 `final-experience-review.md`에서 재사용. 이번 디자인을 위한 실제 AI/TMAP 반복 생성 호출은 하지 않는다. 최종 캡처는 공개 배포의 서울시 실제 데이터 + 수동 시간대 비교로 준비한다.

## 유지하는 제한

실제 휴대폰 GPS/카카오 설치·미설치/PWA와 첫 사용자 관찰은 별도 미완료. TMAP Free 서비스 전체 하루 10건, AI 총 $20 제한 유지. 새로운 검증·효과 수치를 만들어 내지 않는다. 이미지 업로드는 사용자 담당이며 원티드 최종 제출은 하지 않는다.
