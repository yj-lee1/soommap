# 5단계 — 재방문 복원·예측·지도·홈 화면

2026-09-17. 브랜치 `feat/saved-plans-and-place-explorer`. 사용자 네이버지도 연결 성공 확인 및 다음 단계 지시로 착수했다.

## 보관과 복원

- 같은 origin·브라우저의 `localStorage`, 키 `soommap.planner.v1`. 로그인·외부 DB·유료 서비스 추가 없음. 입력 문장, 불완전한 입력 폼, 출발지 이름/좌표, 이동 모드, 처음 조건과 추가 고정/제외, 선택 장소/시각/확정 시각을 자동 보관한다.
- 마지막 저장부터 7일 만료. 재방문 시 저장 내용은 비신뢰 입력으로 검증하고 알려진 필드만 복원한다. 읽을 수 없는 버전·과대 데이터·손상·만료는 삭제 후 빈 입력을 제공한다. 저장 차단/용량 오류는 명시하고 메모리상 작업은 유지한다.
- 저장 내용 삭제 버튼으로 출발 위치와 입력·선택을 모두 지울 수 있다. 입력 화면에서 보관 범위·기간을 알린다. 위치 권한은 자동 재요청하지 않으며 이전 GPS 위치가 현재 위치라는 주장을 하지 않는다.
- TMAP 응답·이동시간·암호화 토큰·혼잡 원자료·AI 응답은 로컬 저장 대상이 아니다. 복원만으로 TMAP/OpenAI를 호출하지 않는다. 페이지의 공공 자료는 기존 서버 캐시로 조회한다.
- 저장된 확정 계획은 이전 선택이라는 별도 패널에서 보여주며, 새 근거 없이 최신 추천이나 현재 선호 충족으로 확정하지 않는다. 확정했던 계획은 같은 출발지·접근 지점으로 즉시 지도 길찾기를 열 수 있다.
- 새 비교는 명시적인 버튼으로 실행한다. 처음 조건과 추가 고정은 구분을 유지해 재비교 뒤에도 추가 고정을 해제할 수 있다. 지난 시각을 오늘로 옮기거나 이동시간 변화에 맞춰 고정 조건을 자동 해제하지 않는다.
- 페이지 내 공공 자료 갱신은 입력·선택을 초기화하지 않는다. 다른 기기/브라우저, 비공개 모드 종료, 사용자의 사이트 데이터 삭제, 다른 도메인 간에는 복원이 보장되지 않는다. 설치된 웹앱의 저장소 분리도 화면에서 안내한다. 오래된 Preview 주소에서 새 주소로 브라우저 저장 내용을 자동 옮기지 않는다.

## 예측 시각화

- 전체 예측은 페이지 확인 시각부터 최대 12시간 내 실제 표본만 표시한다. 혼잡 단계는 범주별 행에 점으로 표시한다. 선·계단 면적으로 표본 사이 상태를 생성하지 않는다.
- 60분 초과 간격은 표시하고, 데이터 없음은 0/여유로 채우지 않는다. 한국 시간·자정 경계·출처/원자료/수신/확인 시각을 표시한다. 접근성을 위한 동등한 표도 제공한다.
- 후보와 선택 패널의 체류 그래프는 해당 계산에 쓰인 동일 표본만 사용하며 도착~체류 종료 구간을 음영으로 구분한다. 전체 탐색 그래프는 별도 조회 자료일 수 있음을 명시한다.

## 위치·집계 영역

- 기존에 검증한 서울시 공식 GeoJSON 5개 영역과 WGS84 좌표를 SVG에 투영한다. 대표 표시점과 실제 접근 지점을 구분하고 공원 번호/버튼으로 탐색한다. 후보 카드에서 해당 공원의 전체 예측으로 이동할 수 있다.
- 실제 도로 지도나 산책로 안내로 표현하지 않는다. 추가 지도 키·외부 타일·추적·지오코딩·요금 없음. 지도는 펼칠 때만 요청하며 실패해도 장소 버튼·예측·추천을 사용할 수 있다.
- 지도 조회는 사용자 조건이나 최종 선택을 바꾸지 않는다. 공식 안내센터 링크를 제공하며 상세 경로는 확정 후 기존 지도 앱으로 연결한다.

## 홈 화면

- 표준 Next.js `manifest.ts`, standalone 실행 설정, 192/512 PNG 임시 아이콘, iOS 180 아이콘·메타데이터와 설치 메뉴 안내.
- 최신 추천은 온라인 기능이다. 서비스 워커로 API/HTML을 오프라인 캐시하지 않으므로 오래된 혼잡·위치 응답이 오프라인에서 현재 정보로 재생되지 않는다. 브라우저별 설치 UI·실기기 홈 화면 실행은 사용자 기기에서 최종 확인한다.

## 이번 단계의 범위

날씨·행사·장소 확장은 조건부 목록에 남긴다. 현재 운영 중인 `citydata_ppltn` 응답에는 날씨·행사가 없으므로 새로운 통합 응답 연결을 이 단계 완료 조건으로 추가하지 않았다. 5개 공원 전체를 비교하면 Free TMAP의 하루 10건 중 최대 5건이 필요하므로 기존 5곳 체험을 먼저 유지한다. 이는 기존 단계 계획의 조건부 범위 결정이며 핵심 추천 품질·조건 검사를 축소하지 않는다. 최종 브랜드·간격·모션은 6단계에서 통합한다.
